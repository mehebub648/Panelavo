# v0.1.116 — Quick server switching

- Add a Super Admin-only current-server selector to the top bar, including local and connected Fleet Nodes.
- Keep server navigation and supported sections on the selected target. Website-specific screens fall back to the other server's website list; account and security settings remain local.
- Make Fleet workspace sections bookmarkable and restore them on browser back/forward navigation.
- Remount target workspaces when switching to avoid showing another server's cached data; show load failures with a safe retry path and wait for user inventory before mounting its manager.
- Keep Fleet protocol 1, broker protocol 24, deployment state preservation, and ordinary-role navigation unchanged.
