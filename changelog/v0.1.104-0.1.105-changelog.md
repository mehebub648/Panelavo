# Panelavo 0.1.104 → 0.1.105

## What changed

- Made website creation wait for its initial Let's Encrypt issuance attempt to complete.
- Returned DNS warnings only after issuance finishes.
- Kept an already-created website intact when DNS or ACME fails and displayed a clear Security-tab retry action.

## Compatibility and migration

- No configuration, data, or broker protocol migration is required.
- Certificate issuance can make the creation request take longer because it now reflects the real ACME result.
