# Panelavo 0.1.103 → 0.1.104

## What changed

- Recorded a root-owned fingerprint of the small default scaffold generated for each new PHP website.
- Allowed Git clone to replace only that exact unchanged scaffold while preserving the ACME `.well-known` directory.
- Cloned into staging before changing the site root and restored the original scaffold if repository promotion failed.
- Kept edited files, added content, directories, links, and unrelated non-empty roots protected by the existing refusal.

## Compatibility and migration

- Broker protocol 20 is required. Run trusted `sudo bash setup.sh` before deploying this application release.
- Existing PHP websites have no creation fingerprint and retain the existing non-empty-root protection.
