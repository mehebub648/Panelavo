# v0.1.112 → v0.1.113

## Panelavo WireGuard VPN host

- Added a dedicated Super Admin-only VPN tab with installation preflight, gateway/service health, provider-firewall guidance, diagnostics, peer statistics, device lifecycle controls, and official platform setup resources.
- Added strict non-cacheable `/api/vpn` contracts with CSRF protection, throttling, typed disruptive-action confirmations, one-time QR/config responses, and secret-safe audit events.
- Added broker protocol 24 with a host-wide lock and one Panelavo-owned `pnlwg0` gateway using distro WireGuard tools, separate root-only state and keys, fixed command arrays, isolated nftables/UFW resources, forwarding rollback, and ownership-aware uninstall.
- Added full-tunnel IPv4 plus fail-closed IPv6 profiles, conditional verified IPv6 egress, public-internet access, public host web access, and explicit isolation from private host services, rootless Docker networks, and other VPN peers.
- Added live peer add/rename/rotate/revoke behavior without restarting other peers, including rollback of tentative rotation state, plus broker rendering/hostile-input self-tests and API/schema/UI coverage.

## Upgrade requirement

Run trusted `sudo bash setup.sh` from this release to install and verify broker protocol 24 before deploying the application update. Setup does not install or activate the VPN; installation remains an explicit Super Admin action from `/vpn` after live preflight and provider-console readiness.
