# Panelavo 0.1.85

## Added

- Added a remote Streamable HTTP MCP server with OAuth discovery, public dynamic client registration, S256 PKCE, short-lived access tokens, rotating refresh tokens, revocation, and per-user connected-assistant management.
- Added live role-aware tools for website discovery, creation, settings, supported site sections, high-level domains/DNS/SSL, linked services, uptime checks, deployment hooks, local/scheduled/off-site backups, deployment, allow-listed Operations and repairs, the unprivileged site Terminal, deletion, and manager server information.
- Added a nontechnical **AI access** page with role explanations, desktop/CLI/IDE setup steps, copyable prompts, connection status, and immediate disconnect controls.

## Security and compatibility

- MCP grants store no role or site assignment. Every request revalidates the stable CloudPanel user id, current Panelavo role, status, and visible sites; revoked or reduced access takes effect immediately.
- OAuth credentials are stored only as HMAC digests. Codes are one-use, refresh tokens rotate with replay-family revocation, and password or MFA changes revoke the account's connections.
- Website mutations retain the browser's shared schemas, section allowlist, linked-service policy, operation preflight, site-user/root-broker boundaries, locks, audit redaction, and Super Admin-only host repair checks.
- Sensitive MCP tools require a short-lived, one-use user confirmation cryptographically bound to the actor, OAuth client, connection, exact tool, and arguments; website deletion also requires the exact domain.

Node.js 20 or newer is required by the MCP SDK. Install the updated frozen dependencies and rebuild Panelavo. No data migration, new listener, firewall rule, OAuth secret, environment variable, or broker protocol change is required.
