# Panelavo 0.1.101 → 0.1.102

## What changed

- Made the privileged creation bridge return the authoritative CloudPanel website record.
- Persisted creation-time labels against that real record ID so the label remains visible after the site list reloads.
- Rejected incomplete or mismatched creation responses instead of inventing a temporary website identity.

## Compatibility and migration

- Broker protocol 19 is required. Run trusted `sudo bash setup.sh` before deploying this application release.
- Existing labels and CloudPanel website records are unchanged.
