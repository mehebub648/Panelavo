# Panelavo 0.1.92 → 0.1.93

## What changed

- Added asynchronous MCP deployments, backups, and allow-listed Operations that return a job ID immediately.
- Added credential- and website-bound job status/list tools with bounded lifecycle logs, result summaries, seven-day retention, and honest interrupted state after process restarts.
- Added confirmed job cancellation and per-job timeouts that terminate the complete privileged broker process group, including child build and deployment commands.
- Preserved existing synchronous MCP tools for compatibility and reused the same live authorization, schema validation, preflight, per-site lock, and root-broker boundaries.

## Compatibility

- No data migration or new dependency is required.
- Existing `.data` remains compatible; `mcp-jobs.json` is created privately on first use.
- Broker protocol 14 is unchanged, so servers already running protocol 14 do not need another trusted `setup.sh` run for this release.
