# v0.1.117 — Connected servers, without Hub/Node roles

- Replace the duplicate sidebar profile card with the Super Admin server switcher; retain one top-bar profile menu and show the selected remote server's name.
- Replace the Fleet dashboard with Settings → Connected servers: generate a token with one click or submit a token. Tokens are single-use, expire after ten minutes, and contain the connection details. No separate activation mode or password/hostname fields.
- Support independent many-to-many, directional connections, including reverse-direction sharing, with editable nicknames and individual disconnection. Connections do not implicitly expose other connected servers.
- Preserve existing encrypted trust through migration from one incoming connection to a collection. Revalidate each connection's authorizing account independently; account-security changes revoke all incoming grants for that account without removing unrelated outgoing connections.
- Move target workspaces to `/servers`, preserve old bookmarks through redirects, and reuse the normal website inventory with server-aware links and API calls.
- Keep the finite remote-action allowlist, signed per-connection keys, live authorization, HTTPS/SSRF checks, local-only account/credential controls, and broker protocol 24 unchanged. Application peer protocol remains 1; use 0.1.117 on each panel for the new Settings workflow.
