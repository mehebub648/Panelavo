# Panelavo 0.1.94 → 0.1.95

## What changed

- Added a dedicated MCP proxy diagnostic that checks only CloudPanel's configured upstream URL with the existing bounded operation.
- Added confirmed, cancellable controlled recovery jobs for the configured application-root ACL invariant, the site's private rootless Docker runtime, and a journaled rootful-to-rootless migration.
- Reused Panelavo's existing site lock, rootless initialization, ownership journal, legacy restart, endpoint verification, and live authorization boundaries instead of introducing a generic privileged command surface.
- Kept migration recovery live CloudPanel Super Admin-only; ACL repair and private-runtime restart remain contained to the writable website's Unix account.

## Compatibility and migration

- Broker protocol increases from 15 to 16. Run trusted `sudo bash setup.sh` before deploying this application release.
- No data migration, dependency, port, or environment change is required.
