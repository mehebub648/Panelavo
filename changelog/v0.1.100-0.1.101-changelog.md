# Panelavo 0.1.100 → 0.1.101

## What changed

- Read the shared PM2 package version directly instead of invoking the PM2 CLI as root during setup.
- Prevented a successful installation from leaving an unused root-owned PM2 daemon running alongside Panelavo's site-user-owned daemon.

## Compatibility and migration

- No application, configuration, or broker protocol migration is required.
- Existing Panelavo PM2 processes remain owned and managed by the CloudPanel site user.
