# v0.1.68 → v0.1.69

- Added per-site daily and weekly UTC backup schedules with configurable 1–100 snapshot retention.
- Scheduled jobs durably claim each due slot, reuse the existing atomic snapshot implementation, skip when the site operations lock is held, and record the last outcome.
- Added the schedule controls and last-run status to the Backups tab.
- Bumped the privileged broker protocol from 5 to 6 for the narrowly allow-listed scheduler action.

## Upgrade requirement

Run `sudo bash setup.sh` after deploying this version. The in-panel updater will refuse the release until broker protocol 6 is installed.

Backups remain local and restores remain in-place overlays; off-site copies are not part of this change.
