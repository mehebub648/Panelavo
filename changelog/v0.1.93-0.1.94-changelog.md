# Panelavo 0.1.93 → 0.1.94

## What changed

- Added managed tar.gz artifact releases for Node.js, static-build, PHP, and Python websites.
- Added root-broker checksum verification, safe archive inspection, bounded entry/unpacked-size policy, required-path checks, environment-file preservation, and staged Operations preflight.
- Added atomic application-root activation, public HTTPS health gating, automatic failure rollback, release listing, and one-command health-gated rollback.
- Retained the original application as the first rollback release and bounded versioned release history to ten site-user-owned trees.
- Explicitly blocked application roots containing mounts and Compose releases until the data-aware deployment contract can validate bind mounts and datastores.

## Compatibility and migration

- Broker protocol increases from 14 to 15. Run trusted `sudo bash setup.sh` before deploying this application release; the in-panel updater will refuse an incompatible broker.
- No application root changes until the first explicitly confirmed successful managed release attempt. The first activation adopts the existing application directory into Panelavo's release set.
- Normal backups and `.data` preservation remain unchanged.
