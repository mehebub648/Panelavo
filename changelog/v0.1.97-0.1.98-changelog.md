# Panelavo 0.1.97 → 0.1.98

## What changed

- Made the fresh-server installer publish PM2 with predictable non-root-readable and executable permissions even when root uses a restrictive umask.
- Changed the PM2 readiness check to validate access as an unprivileged account instead of relying on root's execute access.
- Added an explicit failure when the shared PM2 installation or its non-root execution contract is missing.

## Compatibility and migration

- No application, configuration, or broker protocol migration is required.
- Rerunning trusted `sudo bash setup.sh` repairs an existing root-only PM2 installation before starting Panelavo.
