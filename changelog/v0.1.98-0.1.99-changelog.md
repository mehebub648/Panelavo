# Panelavo 0.1.98 → 0.1.99

## What changed

- Made the installer place the exact CloudPanel `8443/tcp` deny rule before CloudPanel's broader `8433:8443/tcp` allow rule.
- Removed a stale exact deny when `EXPOSE_CLOUDPANEL=true` is explicitly requested so that opt-in remains effective.
- Made a failure to prioritize the private CloudPanel rule stop setup instead of reporting a misleading successful firewall configuration.

## Compatibility and migration

- No application, configuration, or broker protocol migration is required.
- Rerun trusted `sudo bash setup.sh` to repair rule ordering on existing UFW-enabled installations.
