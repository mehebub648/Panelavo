# v0.1.89 → v0.1.90

## Added

- Added an on-demand Disk details analysis that groups allocated root-filesystem storage into complete site-user homes, other home data, operating-system files, system/service data, administrator data, temporary files, and filesystem overhead or unclassified allocation.
- Added per-site-user drill-downs with related domains and Docker-reported image, container, volume, build-cache, and reclaimable figures.
- Added explicit allocated, available, identified, and filesystem-reserved totals plus a cached **Analyze again** control.

## Behavior and safety

- The ordinary resource snapshot remains fast; the deeper scan runs only from Disk details, at low CPU and idle-I/O priority, with bounded paths and execution time.
- Storage analysis is read-only. It does not prune Docker, delete files, restart services, or alter websites.
- Docker drill-down values are labeled as potentially overlapping because images and BuildKit cache can share layers; group totals use the measured site-user home allocation instead.

## Compatibility

- Broker protocol advances from 11 to 12. Existing installations must run trusted `sudo bash setup.sh` before the application update can be installed.
- No environment variable, database migration, dependency, listener, firewall rule, or website downtime is required.
