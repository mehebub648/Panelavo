# Panelavo 0.1.105 → 0.1.106

## What changed

- Added a **Fix port configuration** action to Operations port-mismatch warnings.
- Safely aligns one literal Compose entry mapping to `127.0.0.1:<CloudPanel port>:<container port>` while preserving the container's internal port and restricting published ports to loopback.
- Safely aligns one unique numeric `.env` `PORT` for direct Node.js or Python sites when no conflicting dotenv, ecosystem, package-script, or live-listener authority is detected.
- Re-resolves every repair under the per-site lock, validates the staged source, retains a verified root-owned backup, atomically installs the edit, and leaves restart/deploy to the operator.
- Gives exact manual instructions without editing when the port source is ambiguous, variable-driven, unsafe, or unsupported.

## Compatibility and migration

- Broker protocol 21 is required. Run trusted `sudo bash setup.sh` before deploying this application release.
- Existing source files, running processes, containers, and CloudPanel port settings are unchanged until the confirmed fix is used.
