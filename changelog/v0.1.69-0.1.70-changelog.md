# v0.1.69 → v0.1.70

- Added encrypted per-site S3-compatible destinations for Amazon S3, Backblaze B2, Cloudflare R2, and compatible HTTPS services.
- Scheduled snapshots can stream an automatic off-site copy; existing snapshots can be copied manually.
- Added remote listing, deletion, and local-first restore through the established in-place restore path.
- Added private caller-owned staging and strict bundle validation without granting the panel process broad access to site homes.
- Added `@aws-sdk/client-s3` and bumped the privileged broker protocol from 6 to 7.

## Upgrade requirement

Run `sudo bash setup.sh` after deploying this version. The in-panel updater will refuse the release until broker protocol 7 is installed.

Configure bucket credentials with access limited to the selected prefix. Restore remains an in-place overlay rather than an exact point-in-time replacement.
