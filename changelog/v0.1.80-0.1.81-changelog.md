# Panelavo 0.1.81

## Changed

- Reduced installation addressing to exactly two choices: sslip.io (recommended/default) and custom domain.
- Generated `panel.<ip>.sslip.io`, `database.<ip>.sslip.io`, and `site-<id>.<ip>.sslip.io` hostnames in sslip mode without user-managed DNS.
- Made custom mode show and wait for the required wildcard A record.
- Persisted `addressMode` alongside the base domain, with safe inference for existing installations.
- Removed managed-domain registration controls, endpoint configuration, server code, and documentation.
- Continued issuing individual HTTP-01 certificates; no sslip.io wildcard certificate is requested.
- Preserved `PANEL_DOMAIN` and made trusted installer reruns reuse an existing installation's address settings.

No broker protocol change is required. Existing custom-domain installations remain in custom mode.
