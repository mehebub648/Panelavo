# v0.1.90 → v0.1.91

- Added a Super Admin-only, explicitly confirmed BuildKit cache reclaim to Disk details.
- Cleanup is serialized, runs through each site's exact private rootless Docker socket, retains up to 5 GB per site, and skips Docker versions that cannot enforce the bound.
- Containers, images, volumes, databases, backups, and application files are never pruned by this action.
- Added per-site cleanup results and an authoritative filesystem-level recovered-space total.
- Reduced live resource overhead by polling visible dashboards every thirty seconds and sharing a twenty-five-second server snapshot cache.
- Advanced the privileged broker contract from protocol 12 to 13.

Existing installations must run the trusted `setup.sh` once to install broker protocol 13 before deploying this application release. No data migration or configuration change is required.
