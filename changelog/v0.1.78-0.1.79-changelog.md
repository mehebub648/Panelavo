# Panelavo 0.1.79

## Changed

- Added one shared live-site authorization boundary for site pages, settings, domains, DNS, linked services, monitoring, deploy hooks, backups, browser operations, and automation operations.
- Made missing and unassigned sites indistinguishable with a 404 response.
- Required DNS domains and aliases to belong to a currently accessible live site.
- Validated site ID/category changes before changing upstream or local state and added rollback protection for an overlay failure.

## Security

- A deleted domain recreated for another user no longer inherits access through stale assignments or local metadata.

No migration or broker protocol change is required.
