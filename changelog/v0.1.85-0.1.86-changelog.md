# v0.1.85 → v0.1.86

## Changed

- Made `/resources` render immediately and load its privileged snapshot separately, with a short shared cache and less frequent visible-tab polling.
- Replaced raw process-user rows with website rows that support search, website-type and active filters, sorting, and ten-row pagination.
- Added conservative process attribution for ordinary site users, rootless containers, root Docker containers, and root-owned application processes using ownership, cgroup, application-root, Compose, and upstream-port evidence.
- Switched website memory accounting to proportional set size when available and kept ambiguous/shared work separate from system work instead of guessing.
- Changed disk reporting from whole site-user homes to configured application roots, with a bounded ten-minute cache and explicit shared-root labels.

## Compatibility

- The existing per-user resource array remains in API and MCP responses for older consumers; new consumers can use `websites`, `shared`, `system`, and `attribution`.
- No configuration or data migration is required. This release declares broker protocol 11; the trusted root bridge must be refreshed by the normal `setup.sh` broker installation step before the application can be deployed.
