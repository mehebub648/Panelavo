# v0.1.91 → v0.1.92

- Added resumable MCP artifact uploads that stream raw binary chunks instead of base64, support files up to 2 GiB, and resume from an exact server-reported byte offset.
- Bound each upload to the live CloudPanel user, MCP credential, and writable website; added per-account count/byte quotas and 24-hour expiry.
- Required the declared complete size and SHA-256 checksum before accepting an artifact.
- Added tar.gz/tgz compression and extraction with member-path/type validation that blocks traversal, links, and special entries.
- Disabled Nginx request buffering through trusted setup so artifact chunks do not consume duplicate proxy temporary storage.
- Advanced the privileged broker contract from protocol 13 to 14.

Existing installations must run trusted `setup.sh` once to install broker protocol 14 and the validated Nginx streaming directive before deploying this application release. Existing sites and interactive file-manager behavior remain compatible.
