# Panelavo v0.1.115

## Added

- Added the Super Admin-only Fleet Hub and Node modes, including single-use enrollment, per-connection Ed25519 trust, signed replay-protected envelopes, strict public-HTTPS SSRF protection, key rotation, and revocation.
- Added aggregate Fleet health and website inventories, target-aware remote server and website workspaces, capability-gated actions, correlated Hub/Node audits, and persisted sequential rolling Node updates.
- Added Fleet protocol metadata version 1 while retaining broker protocol 24 and the existing local CloudPanel authorization, site, Docker, backup, terminal, VPN, and update boundaries.

## Security

- Fleet private state is encrypted and atomically persisted under `.data`; private keys and pairing codes are never displayed after their one-time use or written to audit records.
- Every Node request freshly revalidates the enrolling Super Admin's stable CloudPanel identity. Password, MFA, role, reset, disable, deletion, or explicit revocation invalidates or suspends the connection.
- Non-Super Admins cannot discover Fleet navigation or pages and receive `403` from Fleet APIs. Browser-only credentials and security settings remain local to each Node.

## Operations

- Fleet requires publicly resolvable, certificate-valid HTTPS port 443 Panelavo origins. No SSH keys, root credentials, CloudPanel passwords, extra inbound ports, setup changes, or deployment are included.
