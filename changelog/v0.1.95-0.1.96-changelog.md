# Panelavo 0.1.95 → 0.1.96

## What changed

- Added MCP inventory for physically contained LanceDB table directories and existing selective snapshots.
- Added include/exclude table snapshots with a brief, allow-listed rootless Compose quiesce and restart.
- Added checksum- and structure-validated table restore with whole-directory swaps, readiness and numeric JSON data checks, and automatic restoration of prior tables on failure.
- Stored selective snapshots as site-user-owned tar/manifest pairs under `backups/datastores` without exposing private table contents to Node.js or MCP.
- Marked consistency-critical snapshot/restore jobs non-cancellable after start so a client cannot interrupt the site between table-swap phases.

## Compatibility and migration

- Broker protocol increases from 16 to 17. Run trusted `sudo bash setup.sh` before deploying this application release.
- Existing whole-site backups, MCP artifacts, jobs, releases, and rootless projects remain compatible.
- Selective snapshots support safe rootless Compose sites only and do not replace a whole-site backup or the still-pending data-aware Compose artifact deployment contract.
