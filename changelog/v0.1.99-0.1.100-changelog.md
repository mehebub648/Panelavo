# Panelavo 0.1.99 → 0.1.100

## What changed

- Persisted newly generated Super Admin and site-user credentials in a root-only pending handoff before later installer steps can fail.
- Reused the pending credentials on an idempotent retry, then removed the handoff after the successful setup summary.
- Added a clear failure message pointing operators to the protected handoff instead of silently losing a newly created account password.
- Allowed an explicit `ADMIN_PASSWORD` on a trusted setup rerun to reset the matching existing CloudPanel Admin through CloudPanel's supported CLI.

## Compatibility and migration

- No application, configuration, or broker protocol migration is required.
- Existing Admin accounts remain untouched unless `ADMIN_PASSWORD` is explicitly supplied.
- The pending handoff is root-owned mode `0600`, contains base64-encoded handoff values (not encryption), and is deleted after successful setup.
